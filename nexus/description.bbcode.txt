[size=5][b][color=#E8C88A]Press to Gather - Configurable[/color][/b][/size]

Gather nearby harvestable plants and resources when you choose. [b]Hold B on Xbox / Circle on PlayStation for 0.6 seconds[/b] by default, or [b]press O[/b] on your keyboard. The gathering distance defaults to [b]20 metres[/b] and can be set from [b]10 to 200 metres in 10-metre steps[/b], using the Mod Setting Menu or the settings file.

This mod builds on [url=https://www.nexusmods.com/thebloodofdawnwalker/mods/381]Toggleable Auto Gather - Press to Gather by Tic0311[/url] with a configurable controller hold shortcut and an in-game gathering distance setting from 10 to 200 metres. Tic0311 credits [url=https://www.nexusmods.com/thebloodofdawnwalker/mods/205]Auto Gathering by Volitio[/url] as the inspiration for the original mod.

[size=4][b][color=#E8C88A]Controls and features[/color][/b][/size]

[list]
[*]Hold your chosen controller button for 0.6 seconds; the default is [b]B / Circle[/b]. Release the button to gather again.
[*]Choose from [b]14 controller buttons[/b] and select the gathering distance in the [b]Mod Settings[/b] menu or edit the settings file.
[*]Gathers eligible harvestable resources and [b]17 additional wild plant types[/b], including Cave Fungus, Comfrey and Green-Gilled Mushroom. Owned and quest-marked plants are excluded.
[/list]

[size=4][b][color=#E8C88A]Reporting Bugs and other issues[/color][/b][/size]

If you encounter an issue, set [b]Logging[/b] to [b]On[/b] in this mod’s Mod Setting Menu settings, apply the change, reproduce the issue. Then start either a bug report in the Bugs tab on Nexus (preferred method for me to track things), or at least start a new thread in comments and send me [b]Dawnwalker/Binaries/Win64/ue4ss/UE4SS.log[/b] from your game folder. Do not report unrelated bugs in other people's threads, please, this makes it impossible for me to track issues.

[size=4][b][color=#E8C88A]Configuration[/color][/b][/size]

Apply saves changes and updates gameplay. Enable HookProcessConsoleExec = 1 in your Vortex-managed UE4SS configuration.

Defaults are [b]20 metres[/b] and [b]B / Circle held for 0.6 seconds[/b].

[b][color=#A8D5C2]With the menu:[/color][/b] Open [b]Main Menu → Mod Settings → Press to Gather - Configurable[/b]. Set [b]Gather Distance[/b] and [b]Gather Button[/b], select [b]Apply[/b] to update gameplay. Restarting the game also applies the saved settings.

[b][color=#A8D5C2]Manual file editing:[/color][/b]
[list=1]
[*]Launch the game once with the mod enabled, then close it.
[*][b][color=#A8D5C2]Open this generated file in a text editor:[/color][/b]
[/list]
[code]<game>/Dawnwalker/Binaries/Win64/ue4ss/Mods/PressToGather/settings.ini[/code]
In its existing [b][Settings][/b] section, change [b]GatherRadiusMeters[/b] to a value from [b]10 to 200[/b], in steps of [b]10[/b]. Set [b]GatherButton[/b] using the values below. Keep the other entries. The default values are:
[code][Settings]
GatherRadiusMeters = 20
GatherButton = 0
debugLogging = 0[/code]
[b][color=#A8D5C2]GatherButton values (Xbox / PlayStation):[/color][/b]
[code]0 = B (default) / Circle
1 = A / Cross
2 = X / Square
3 = Y / Triangle
4 = LB / L1
5 = RB / R1
6 = LT / L2
7 = RT / R2
8 = Left stick click / L3
9 = Right stick click / R3
10 = D-pad Up
11 = D-pad Down
12 = D-pad Left
13 = D-pad Right[/code]
[b]Save the file and restart the game.[/b] Your saved distance and button are read at startup. Other game actions assigned to the chosen button still work.

[b]Logging[/b] is Off by default. Enable it using the menu's final entry or by setting [b]debugLogging = 1[/b] in the same file; [b]0[/b] turns it off. Messages appear in
[code]Dawnwalker/Binaries/Win64/ue4ss/UE4SS.log[/code].

Logging includes separate plant counts and reasons for skipped pickups, with up to three plant examples per gather. To investigate a missed plant, enable Logging, try Gather beside it, then check UE4SS.log.
